# 小剧场收藏夹 Mini Theater Vault
作者：不须归

**介绍**：

一个 SillyTavern 第三方扩展，用来本地保存你所创作的"小剧场"提示词，
支持作者标注、分类/标签/搜索/排序/折叠/内存查看/自定义阈值/批量删除，并可一键插入或发送到聊天框。

**严禁商业化！！！**

## 安装方法

**方法一：手动放置（推荐，最稳）**

1. 找到你的 SillyTavern 安装目录，进入：
   `SillyTavern/public/scripts/extensions/third-party/`
2. 把整个 `mini-theater-vault` 文件夹复制进去，得到路径：
   `SillyTavern/public/scripts/extensions/third-party/mini-theater-vault/`
3. 重启 SillyTavern（或刷新网页即可，不需要重启后端）。
4. 打开左下角「扩展」（插头图标）面板，找到「小剧场收藏夹 Mini Theater Vault」，勾选启用。

**方法二：通过 Git 安装**

如果你把这个文件夹上传到了自己的 GitHub 仓库，也可以在 SillyTavern 的
「扩展」→「安装扩展」里粘贴仓库地址来安装，效果相同。

## 使用方法

1. 安装并启用后，点击顶部「扩展」菜单（魔法棒图标）里的
   **「小剧场收藏夹」**，会弹出收藏夹面板。
2. 点击右上角 ➕ 新增一条小剧场：
   - **标题**：方便识别，比如"平安时期服饰·万屋闲逛"
   - **作者**：写你自己的名字/昵称，多人共用素材库时便于区分
   - **分类**：如"日常""约会""历史""节日"，也可以自己输入新分类
   - **标签**：逗号分隔，如 `服饰,历史,搞笑`，用于搜索
   - **正文**：把完整的小剧场提示词粘贴进去，`{{user}}` `{{char}}`
     宏可以正常保留，发送时 SillyTavern 会照常自动替换
3. 保存后会出现在列表里，可以用顶部搜索框按标题/内容/标签/作者搜索，
   也可以用分类下拉框筛选。
4. 每条小剧场下方有几个按钮：
   - **发送**：直接把内容填入聊天输入框并立刻发送
   - **插入**：只填入输入框，不自动发送，方便你先检查/修改
   - **复制**：复制到系统剪贴板
   - **编辑 / 删除**：修改或移除这条记录

## 数据存储与备份

- 所有数据保存在 SillyTavern 自身的扩展设置里（随你的用户配置一起持久化，
  不是浏览器 localStorage，换设备登录同一账号也能看到）。
- 面板右上角提供 **导出**（下载为 JSON 备份文件）和 **导入**（读取 JSON
  批量恢复/合并）功能，建议定期导出备份，或者用来在多个 SillyTavern
  实例之间迁移你的小剧场库。
- 占用中的数据设置也会随着 **导出**一同导出。

## 注意事项

- 本扩展依赖 SillyTavern 页面里固定的 `#send_textarea` 和 `#send_but`
  两个元素 ID 来实现"插入/发送"。如果未来 SillyTavern 大版本更新改了这两个
  ID，"插入/发送"按钮可能会失效，但"复制"按钮总是可用，可以手动粘贴。
- 内容较长（比如 4000 字以上的小剧场）也可以正常保存和发送，没有长度限制。
